# 国际化支持 Internationalization

## 概述 Overview

插件支持中文和英文两种语言，根据设备的系统语言自动切换。

## 集成方式 Integration

### 在 MaterialApp 中配置 Configure in MaterialApp

```dart
import 'package:pd_load_state/pd_load_state.dart';

MaterialApp(
  localizationsDelegates: [
    GlobalMaterialLocalizations.delegate,
    GlobalCupertinoLocalizations.delegate,
    GlobalWidgetsLocalizations.delegate,
    PDLoadStateLocalizationsDelegate(),
  ],
  supportedLocales: const [
    Locale('en'),
    Locale('zh'),
  ],
  home: const MyHomePage(),
);
```

### 在 CupertinoApp 中配置 Configure in CupertinoApp

```dart
CupertinoApp(
  localizationsDelegates: [
    GlobalMaterialLocalizations.delegate,
    GlobalCupertinoLocalizations.delegate,
    GlobalWidgetsLocalizations.delegate,
    PDLoadStateLocalizationsDelegate(),
  ],
  supportedLocales: const [
    Locale('en'),
    Locale('zh'),
  ],
  home: const MyHomePage(),
);
```

## 支持的语言 Supported Languages

| 语言 | 代码 | 说明     |
| ---- | ---- | -------- |
| 中文 | `zh` | 简体中文 |
| 英语 | `en` | English  |

## 自定义国际化 Custom Internationalization

### 创建自定义本地化类 Create Custom Localizations Class

```dart
class CustomPDLoadStateLocalizations extends PDLoadStateLocalizations {
  const CustomPDLoadStateLocalizations();

  @override
  String get loading => '自定义加载中...';

  @override
  String get error => '自定义错误信息';

  @override
  String get errorButton => '自定义重试';

  @override
  String get errorTitle => '自定义错误标题';

  @override
  String get empty => '自定义空数据';

  @override
  String get emptySubtitle => '自定义空数据副标题';

  @override
  String get completion => '自定义完成';

  @override
  String get idle => '自定义空闲';

  @override
  String get offline => '自定义离线';

  @override
  String get offlineButton => '自定义重新连接';

  @override
  String get offlineTitle => '自定义离线标题';
}
```

### 创建自定义代理类 Create Custom Delegate

```dart
class CustomPDLoadStateLocalizationsDelegate
    extends LocalizationsDelegate<PDLoadStateLocalizations> {
  const CustomPDLoadStateLocalizationsDelegate();

  @override
  bool isSupported(Locale locale) {
    return ['zh', 'en', 'ja'].contains(locale.languageCode);
  }

  @override
  Future<PDLoadStateLocalizations> load(Locale locale) async {
    switch (locale.languageCode) {
      case 'ja':
        return const JapanesePDLoadStateLocalizations();
      default:
        return super.load(locale);
    }
  }

  @override
  bool shouldReload(covariant LocalizationsDelegate<PDLoadStateLocalizations> old) {
    return false;
  }
}
```

### 使用自定义代理 Use Custom Delegate

```dart
MaterialApp(
  localizationsDelegates: [
    GlobalMaterialLocalizations.delegate,
    GlobalCupertinoLocalizations.delegate,
    GlobalWidgetsLocalizations.delegate,
    CustomPDLoadStateLocalizationsDelegate(),
  ],
  supportedLocales: const [
    Locale('en'),
    Locale('zh'),
    Locale('ja'),
  ],
);
```

## 获取本地化文本 Get Localized Text

```dart
final localizations = PDLoadStateLocalizations.of(context);
print(localizations?.loading);
print(localizations?.error);
```

## 强制指定语言 Force Language

```dart
MaterialApp(

  localizationsDelegates: [
    GlobalMaterialLocalizations.delegate,
    GlobalCupertinoLocalizations.delegate,
    GlobalWidgetsLocalizations.delegate,
    PDLoadStateLocalizationsDelegate(),
  ],
);
```
